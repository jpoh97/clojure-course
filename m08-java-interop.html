Java Interop for JVM Veterans

Your years of Java knowledge are not wasted — every library and idiom you know is one syntax away. Plus: typed data with records and protocols.

Goals
  • Call Java methods, constructors, statics and fields fluently.
  • Leverage java.time, BigDecimal and Maven dependencies directly.
  • Create typed domain values with defrecord.
  • Add polymorphism with defprotocol/extend-type and reify.

The interop syntax tour

;; instance method:
(.toUpperCase "clojure")            ;=> "CLOJURE"
(.isBefore (java.time.LocalDate/now)
           (java.time.LocalDate/of 2030 1 1))

;; constructor - the dot suffix:
(java.util.ArrayList. [1 2 3])
(new java.util.HashMap)             ; same thing, longer form

;; static method / field:
(Math/abs -5)                       ;=> 5
(java.lang.Integer/MAX_VALUE)       ;=> 2147483647
(System/getenv "HOME")

;; chained calls with the .. macro:
(.. (java.time.LocalDate/now) getDayOfWeek toString)

;; builder-style mutation with doto:
(doto (java.util.HashMap.)
  (.put "env" "prod")
  (.put "shards" 8))

defrecord: typed data without Lombok

(defrecord User [id email roles])

(def u (->User 1 "ada@x.io" #{:admin}))   ; positional factory
(:email u)                                ;=> "ada@x.io"
(u :email)                                ;=> "ada@x.io"  still map-like!
(assoc u :premium true)                   ; works like a map

;; shape-changing ops return plain maps:
(assoc u :anything-new 42)                ;=> a map now, not a User

(map? u)                                  ;=> false (but associative? => true)
= compares records by fields, like Kotlin data classes.
Coming from Java/Kotlin

defrecord generates a final class with an immutable-fields constructor, correct equals/hashCode/toString and keyword accessors — essentially a Lombok @Value / Kotlin data class in one line, that also behaves like a map so all of Module 03's tools apply. Use records for hot paths and stable domain entities; plain maps everywhere else.

Protocols: interfaces you can add to any type

(defprotocol Area
  "Things that occupy space."
  (area [shape]))

(defrecord Rect [w h]
  Area
  (area [_] (* w h)))

(defrecord Circle [r]
  Area
  (area [_] (* Math/PI r r)))

(area (->Rect 2 3))          ;=> 6
(area (->Circle 1))          ;=> 3.14159...

;; retro-fit types you don't own:
(extend-type String
  Area
  (area [s] (count s)))
(area "hello")               ;=> 5

;; inline implementations (anonymous-class style):
(def task
  (reify Runnable
    (run [_] (println "running!"))))
(.start (Thread. task))

Protocol dispatch is by type, compiled to fast JVM calls (no reflection). When dispatch should depend on a value instead (e.g., a :type field), multimethods are the tool:

(defmulti fee :tier)
(defmethod fee :free   [_] 0)
(defmethod fee :pro    [_] 9)
(defmethod fee :default [_] 49)

(fee {:tier :pro})           ;=> 9

Type hints & arrays, briefly

;; reflection warnings tell you where interop can't infer a type:
(set! *warn-on-reflection* true)

;; a hint silences them and restores primitive speed:
(defn shout [^String s] (.toUpperCase s))

;; raw arrays when a library demands them (otherwise use vectors):
(def arr (into-array String ["a" "b"]))
(aget arr 0)                 ;=> "a"
(alength arr)                ;=> 2

Packaging it up

clj -T:build uber (tools.build) or lein uberjar produce a fat jar exactly like Spring Boot's — java -jar app.jar and you're deployed. The GraalVM native-image story also applies, and Babashka (Module 01) is precompiled Clojure for instant-start scripts.

Where this is used for real

This module is why enterprises adopt Clojure incrementally: Kafka producers, AWS SDK calls, Netty handlers and Hikari pools are used directly, while business logic stays functional. Tasks

Task 1Date arithmetic. Compute how many days until next New Year using only LocalDate interop.
Solution 
;; .until with a ChronoLocalDate returns whole days:
(.until (java.time.LocalDate/now)
            (java.time.LocalDate/of 2027 1 1))
;=> e.g. 126

;; explicit unit version:
(.until (java.time.LocalDate/now)
            (java.time.LocalDate/of 2027 1 1)
            java.time.temporal.ChronoUnit/DAYS)
Task 2Money record. Define (defrecord Money [amount currency]), create EUR 5.00, and implement a Display protocol with (show m) returning "EUR 5.00".
Solution 
(defprotocol Display (show [x]))

(defrecord Money [amount currency]
  Display
  (show [_] (str currency " " (format "%.2f" amount))))

(show (->Money 5.0M :eur))    ;=> ":eur 5.00" - store currency as string to be neat
Task 3Builder pattern, gone. Build a StringBuilder containing "a-b-c" using doto.
Solution 
(str (doto (StringBuilder.)
       (.append "a") (.append "-") (.append "b")
       (.append "-") (.append "c")))
;=> "a-b-c"
Task 4Catch the overflow. Call (/ 1 0), catch the exception, and print its message.
Solution 
(try (/ 1 0)
  (catch ArithmeticException e
    (println (.getMessage e))))
;=> Divide by zero
Task 5Retrofit behavior. Extend Number-like behavior onto Long: make (show 5) return "#5" via your Display protocol from Task 2.
Solution 
(extend-type Long
  Display
  (show [n] (str "#" n)))

(show 5)      ;=> "#5"

Summary · what you covered
  • Call everything Java: instance methods (.length s), constructors (Date.), statics/fields (Math/PI), and system calls (System/getenv).
  • Chaining & building: .. chains method calls, doto repeatedly mutates one receiver (efficient for builders).
  • Leverage Java directly: java.time, BigDecimal for exact money, UUID — no Clojure wrappers needed.
  • The whole Maven universe: declare Jackson, HikariCP, Kafka, AWS SDK in deps.edn exactly like Gradle coordinates.
  • Typed data & polymorphism: defrecord for immutable value objects (with map behavior + assoc), defprotocol/extend-type/reify, and defmulti for value-based dispatch.

Exam · Module 08

1 · How do you call the instance method isEmpty on object s?
A leading dot means "call this method on the first argument": (.isEmpty s), optionally followed by method arguments.
2 · What does (java.util.Date.) do?
The trailing dot sugar constructs an object; (new java.util.Date) is the explicit equivalent.
3 · A record updated with assoc using a brand-new key…
Records preserve their type only across operations that keep their declared fields; adding/removing keys yields ordinary maps.
4 · When would you pick a multimethod over a protocol?
Protocols dispatch on type; multimethods dispatch via any function of the arguments - tags, tuples, arbitrary logic.
5 · Where do third-party Java libraries come from in a Clojure project?
Clojure consumes the entire Maven ecosystem natively - Jackson, Kafka clients, AWS SDK, HikariCP - with identical versioning semantics.
