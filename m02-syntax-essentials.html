Syntax Essentials

The entire grammar of Clojure in one sitting: expressions, scalar values, keywords, vars, namespaces and truthiness.

Goals
  • Understand that everything is an expression evaluated to a value.
  • Know all scalar types and when keywords are used.
  • Avoid the truthiness trap coming from JavaScript/Kotlin.
  • Read namespace declarations and naming conventions fluently.

Everything is an expression

Java splits the world into statements and expressions. Clojure only has expressions — every form evaluates to a value, including if, let and function bodies:

(def label (if (> 3 2) "bigger" "smaller"))
;=> #'user/label        ; the if returned a string, def bound it

(let [x 10]
  (* x x))
;=> 100                 ; let itself is an expression

Evaluation rule. The reader parses your text into data structures. Then:

  • Atoms (42, "hi", :kw) evaluate to themselves.
  • Symbols evaluate to whatever they refer to (a var, a parameter…).
  • A list (f a b) means a call: first element is the function/macro/special form, rest are arguments.
(+ 1 2)            ;=> 3
(- 10 3)           ;=> 7
(< 1 2 3)          ;=> true     ; comparisons chain!
(max 4 9 2)        ;=> 9
Coming from Java/Kotlin

Parentheses mean call this, never grouping. There is no operator precedence table to memorize: prefix notation is unambiguous, and operators accept any number of arguments. Kotlin's val x = if (c) a else b already taught you expression-oriented thinking — Clojure takes it everywhere.

The scalars

42 -17             ; longs
3.14 1.5e3         ; doubles
22/7               ; ratios! exact fractions, not floating point
(+ 1/3 1/6)
;=> 1/2
0xFF               ;=> 255   (hex)

"a string"         ; java.lang.String, immutable as usual on the JVM
\a \newline \space ; character literals

true false nil     ; nil = null, but a proper value

:error :status     ; keywords - self-evaluating identifiers
:user/email        ; namespaced keyword
::local            ; resolves in current ns, e.g. :my.app/local

Ratios and overflow. Integer math stays exact until it overflows — loudly, like Kotlin's Math.addExact:

(+ 9223372036854775807 1)
;; ArithmeticException integer overflow
(+' 9223372036854775807 1)
;=> 9223372036854775808N       ; auto-promoted BigInt (note the N)

Keywords vs symbols. A symbol (x, map) refers to something; a keyword (:email) names something — typically a map key or an enum-like tag. Keywords are interned: comparing them is pointer-fast.

Truthiness: the #1 porting bug

Only two values are falsy: nil and false. Everything else is truthy —

(if 0     :truthy :falsy)   ;=> :truthy   (!)
(if ""    :truthy :falsy)   ;=> :truthy   (!)
(if []    :truthy :falsy)   ;=> :truthy
(if nil   :truthy :falsy)   ;=> :falsy
(if false :truthy :falsy)   ;=> :falsy

(and 1 2 3)                 ;=> 3      (and/or return values, not booleans)
(or false nil :fallback)    ;=> :fallback   ; idiomatic defaulting
(or (:port config) 8080)
Gotcha

If you come from JavaScript or Python, 0 and empty strings/collections being truthy will bite you once. Coming from Java/Kotlin it maps better to Objects::isNull-style checks: think of (if x ...) as "if x is neither null nor false".

Vars with def, locals with let

(def max-retries 3)              ; top-level var in this namespace
max-retries                      ;=> 3

(let [base-url "https://api.io"  ; lexical, immutable bindings
      path "/users"
      url (str base-url path)]   ; later bindings see earlier ones
  url)
;=> "https://api.io/users"
  • Prefer let for local computation; use def for genuinely top-level things (config, constants).
  • Bindings are immutable — no reassignment exists. Where you would mutate a local, use a new binding or recursion (Module 05).

Namespaces = modules + imports

(ns myapp.orders                       ; file lives at src/myapp/orders.clj
  (:require [clojure.string :as str]   ; lib -> alias
            [myapp.db :as db])
  (:import [java.time LocalDate ZoneId]))   ; Java classes

(defn overdue? [due-date]
  (.isBefore due-date (LocalDate/now)))
  • Namespace name mirrors the file path exactly, like Java packages but with dashes mapping to underscores on disk.
  • :require pulls in other namespaces; aliases keep call sites short (str/blank?).
  • :import is only needed for Java classes used without full qualification.

Comments and equality

;; single-line comment
#_(this-form-is-discarded-by-the-reader even-if-invalid)

(comment
  (risky-experiment 1)
  (risky-experiment 2))     ; scratchpad, evaluate forms individually

(= [1 2] '(1 2))            ;=> false  (different collection types)
(= {:a 1} {:a 1})           ;=> true   structural equality by value
(== 1 1.0)                  ;=> true   numeric equality across types
(identical? :a :a)          ;=> true   keywords are interned
Where this is used for real

Because keywords and maps are literal syntax, configuration files, Ring routes, Reitit route tables, Malli schemas and system definitions are all written as plain EDN data — the same notation you just learned. One syntax for code, config, queries and API payloads.

Tasks

Task 1Temperature converter. Using let, convert 25 °C to Fahrenheit inside a REPL form, binding intermediate steps.
Solution 
(let [celsius 25
      fahrenheit (+ (* celsius 9/5) 32)]
  fahrenheit)
;=> 77
Task 2Predict, then verify. For each of 0, "", [], nil, false, predict whether (if v :t :f) yields :t or :f, then check yourself in the REPL.
Solution 
(map #(if % :t :f) [0 "" [] nil false])
;=> (:t :t :t :f :f)     ; only nil/false are falsy
Task 3Exact math. Compute one third plus one sixth twice: once with ratios, once with doubles. Which would you trust for currency math?
Solution 
(+' 1/3 1/6)      ;=> 1/2
(+ 0.3333333333333333 0.16666666666666666)
;=> 0.49999999999999994
;; In production you would reach for BigDecimal via interop (Module 08).
Task 4Your first function template. Evaluate this and call it three times (full treatment arrives in Module 04): 
(defn greet [name] (str "Hello, " name "!"))
Solution 
(greet "Ada")     ;=> "Hello, Ada!"
(greet "Linus")   ;=> "Hello, Linus!"
(greet "")        ;=> "Hello, !"   ; empty string is still truthy

Exam · Module 02

1 · Which values are falsy in Clojure?
Clojure has minimal falsiness: exactly nil and false. Zero and empty collections are truthy - unlike JavaScript or Python.
2 · What does :status evaluate to?
Keywords evaluate to themselves, which makes them perfect stable tags and map keys.
3 · Why prefix notation like (< 1 2 3)?
Prefix calls remove precedence rules entirely and let comparison/arithmetic operators be variadic.
4 · What is (= 1/3 (/ 1 3))?
(/ 1 3) returns the ratio 1/3, not 0.333..., so both sides are identical values. Use == to compare numerically across types.
5 · What does (def retries 3) do?
def interns a top-level Var. Locals come from let or function parameters.
